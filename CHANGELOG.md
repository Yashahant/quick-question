# Changelog

## 0.5.0

- Initial public source distribution of the Direct Reader v5 implementation.
- Windows accessibility reading with Windows OCR fallback.
- Full prompt/image paste and optional answer/Next clicks.
- Variable option counts (1–99), including five-option response regression coverage.
- Preview mode, request-code validation, cancellation, and activity status.
- Build script and usage/customization documentation.

No personal runtime files or assessment screenshots are included in the source release.
